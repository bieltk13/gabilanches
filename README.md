# Gabi Lanches — site One Page

Site estático completo (HTML, CSS, JavaScript e imagens locais). Layout desenvolvido a partir do mockup visual aprovado.

## Como abrir

Abra `index.html` ou publique a pasta inteira no GitHub Pages. Não envie apenas o HTML: as pastas `assets/`, `css/` e `js/` precisam acompanhar o arquivo. Não é necessário banco de dados, Node.js, PHP ou APIs.

## Pedidos: apenas WhatsApp

**Não existe compra, carrinho, checkout, pagamento ou cadastro no site.** Todos os botões de pedido e todos os cards de produtos abrem conversa com o WhatsApp comercial **(45) 98825-8255**. Cada item inclui uma mensagem inicial apropriada; o botão de cardápio completo solicita cardápio e preços ao atendente.

## Conteúdo a confirmar com o proprietário antes de publicar como site oficial

- O catálogo e as fotos dos produtos são **ilustrativos**, extraídos do mockup aprovado. Confirmar produtos, ingredientes, preços e disponibilidade. Não foram usados fotos reais cedidas pelo estabelecimento.
- A imagem da fachada é **ilustrativa**, não uma fotografia oficial confirmada.
- Confirmar horários e endereço. O horário inicial 18h30 veio da captura de tela do WhatsApp, mas os dias e horário de encerramento não foram confirmados.
- O Instagram oficial não foi verificado e, por isso, não há link de perfil inventado.
- A seção de avaliações usa **textos de preenchimento identificados como tal**, e não avaliações fictícias atribuídas a clientes.
- Logo textual adaptado do mockup aprovado; para publicação definitiva, substituir pelo arquivo original autorizado se necessário.
- Nenhuma promoção, preço ou entrega em tempo determinado foi prometida.
